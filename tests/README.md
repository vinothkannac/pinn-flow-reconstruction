# tests

Run with `pytest -q` from the main folder.

* `test_residuals.py` the Navier-Stokes residual against a Taylor-Green field with a known answer
* `test_data_loading.py` the OpenFOAM reader, centerlines, Ghia loader and sensor files
* `test_geometry.py` boundary points, collocation points, config overrides and a tiny training run
